# کابینت چارگوش

یک برنامهٔ خودکار و آفلاین برای مدیریت پروژه‌ها، CRM مشتریان و حسابداری.

## ویژگی‌ها

- داشبورد و KPI
- مدیریت پروژه‌ها
- CRM مشتریان
- حسابداری و فاکتورها
- برد مراحل (Kanban)
- تقویم کاری
- گزارش‌های تحلیلی
- ذخیره‌سازی محلی با localStorage
- خروجی JSON برای پشتیبان‌گیری
- رابط کاملاً فارسی و RTL

## اجرا

فقط کافی است فایل‌ها را روی یک سرور محلی یا در پروژهٔ سادهٔ HTML باز کنید:

```bash
python -m http.server 8000
```

سپس در مرورگر این آدرس را باز کنید:

```text
http://localhost:8000
```
